## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/samora-ecommerce-platform.git
```

**2. Navigate to the project**

```bash
cd samora-ecommerce-platform
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file using `.env.example` and configure your MongoDB connection and required secrets.

Example:

```env
PORT=5000
NODE_ENV=development
MONGODB_URI=mongodb://127.0.0.1:27017/samora
SESSION_SECRET=your_secure_random_secret
```

**5. Start the application**

Use the command configured in your `package.json`:

```bash
npm start
```

**6. Open in your browser**

```text
http://localhost:5000
```
